# 问题重构 - 详细指南

## 核心能力

很多时候，问题本身就是错的。真正高级的人不是解决问题，而是重新定义问题。

## 重构层次

| 层次 | 方法 | 示例 |
|------|------|------|
| 层次 1 | 改变问题词汇 | "如何提高销量？" → "如何让用户更愿意购买？" |
| 层次 2 | 改变问题焦点 | "如何提高加班效率？" → "为什么需要加班？" |
| 层次 3 | 改变问题边界 | "如何改进产品？" → "如何帮助用户完成任务？" |
| 层次 4 | 改变问题方向 | "如何留住用户？" → "为什么用户会离开？" |
| 层次 5 | 彻底重新定义 | "如何设计更好的马车？" → "如何实现高效移动？" |

## 重构技术

1. 向上抽象 - 从具体跳到更高层目标
2. 向下具体 - 从抽象跳到可操作切入点
3. 反向提问 - 从"如何做"跳到"是什么阻止"
4. 前提质疑 - 挑战问题本身的前提
5. 角色转换 - 从不同利益相关者角度

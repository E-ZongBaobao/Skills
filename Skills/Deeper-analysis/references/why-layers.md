# 连续追问 - 详细指南

## 核心能力

不停追问"为什么"，从表层现象深入到根本动机和系统结构。

## 追问层次

```
现象 → 行为 → 情绪 → 动机 → 系统结构
```

### 第 1 层：现象 (What)
发生了什么？看到了什么具体表现？

### 第 2 层：行为 (How)
人们是怎么做的？具体的行为和选择是什么？

### 第 3 层：情绪 (Feel)
人们感受如何？什么情绪在驱动或阻碍？

### 第 4 层：动机 (Why)
人们真正想要什么？底层需求是什么？

### 第 5 层：系统结构 (System)
什么结构塑造了这些行为？哪些规则/激励/约束在起作用？

## 经典案例

### 案例 1：用户不坚持运动

| 层次 | 追问 | 洞察 |
|------|------|------|
| 现象 | 用户不运动 | 健身 App 留存低 |
| 行为 | 为什么坚持不了？ | 用户经常中断 |
| 情绪 | 为什么运动会痛苦？ | 运动=痛苦=逃避 |
| 动机 | 为什么运动必须痛苦？ | 传统运动门槛高 |
| 系统 | 能否在娱乐中完成？ | 游戏化健身机会 |

### 案例 2：共享经济

| 层次 | 追问 | 洞察 |
|------|------|------|
| 现象 | 酒店房间不够/太贵 | 旅游住宿难 |
| 行为 | 人们为什么住酒店？ | 需要临时住宿 |
| 情绪 | 一定要住酒店吗？ | 只是需要床 |
| 动机 | 谁有空闲房间？ | 大量闲置房源 |
| 系统 | 如何连接供需？ | Airbnb 模式 |

## 追问技巧

- 保持好奇，而非质疑
- 每次只问一个为什么
- 追问"不"的问题
- 追问极端情况

# 反事实思维 - 详细指南

## 核心能力

先怀疑现实，再重构现实。从"为什么"到"如果"到"怎样"。

## 思维结构

```
为什么 → 如果 → 怎样
```

## 反事实问题类型

| 类型 | 问题 | 示例 |
|------|------|------|
| 消除前提 | 如果不需要 [X] 会怎样？ | 如果不需要登录会怎样？ |
| 反转假设 | 如果反过来会怎样？ | 如果用户付钱给我们，我们付费给用户？ |
| 极端化 | 如果是 10 倍/零会怎样？ | 如果完全免费会怎样？ |
| 跨界组合 | 如果 [A] 做 [B] 的事？ | 如果用游戏的方式做教育？ |

## 经典案例

- 如果手机没有键盘？ → iPhone
- 如果酒店不属于酒店公司？ → Airbnb
- 如果汽车不需要司机？ → 自动驾驶

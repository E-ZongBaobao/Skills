# FABE 自检清单

## 写完后的四个检验问题

### B 检验
> **读给一个陌生人，他能说出「这说的就是我」吗？**

- [ ] 文案中是否有具体的使用场景？
- [ ] 用户能否一眼看出"这对我有什么用"？
- [ ] 是否避免了需要查资料才能理解的词汇？

**如果不能，B 层还没写到位**

---

### F 检验
> **用了「这意味着」连接 B 层了吗？**

- [ ] 每个技术特性是否都连接了用户利益？
- [ ] F 层是否孤立存在？
- [ ] 用户是否知道为什么要在乎这个特性？

**如果 F 层是孤立的，用户不知道为什么要在乎**

---

### A 检验
> **A 层有明确的比较对象吗？**

- [ ] 是否有具体的比较对象（和什么比）？
- [ ] 是否使用了「最、首、重新定义」等空洞词汇？
- [ ] 是否有具体数据支持？

**如果用了「最、首、重新定义」，删掉重写**

---

### E 检验
> **有没有让用户不需要相信你的证据？**

- [ ] 是否有数据支持？
- [ ] 是否有第三方认证？
- [ ] 是否有用户证言？
- [ ] 是否有可验证承诺？

**数据、认证、用户证言、可验证承诺，至少一个**

---

## 按受众的专项检查

### 普通消费者
- [ ] 是否让用户在脑子里看到具体生活画面？
- [ ] B 层是否为核心，篇幅最多？
- [ ] F 层是否点到为止，没有过多参数？
- [ ] A 层是否用日常生活中的比较对象？
- [ ] E 层是否用生活场景和故事呈现？
- [ ] 是否有任何需要查资料才能理解的词汇？

### 媒体编辑
- [ ] B 层是否有故事性，能作为新闻角度？
- [ ] F 层是否有足够深度供挖掘？
- [ ] A 层是否为核心，突出差异化？
- [ ] E 层是否可验证，提供可核实的来源？

### 技术发烧友
- [ ] B 层是否能引起圈层认同？
- [ ] F 层是否详细完整，参数准确？
- [ ] A 层是否有真实对比数据？
- [ ] E 层是否可自验证，提供验证方法？

---

## 快速检查流程

```
1. 通读全文 → 能否说出「这说的就是我」？
2. 检查 F 层 → 是否都用「这意味着」连接 B 层？
3. 检查 A 层 → 是否有明确比较对象，无空洞词汇？
4. 检查 E 层 → 是否至少有一个可信证据？
5. 确认受众 → 按对应受众专项检查点检查
```

---

## 思考顺序验证

- [ ] 是否按 **B → F → A → E** 的顺序思考？
- [ ] B 层是否决定用户愿不愿意继续听？
- [ ] F 层是否决定用户信不信？
- [ ] A 层是否决定用户为什么选你？
- [ ] E 层是否决定用户敢不敢买？

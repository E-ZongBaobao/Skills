## life-pattern-explorer

**MVP 版本 - 从碎片记录中发现重复模式的 AI 系统**

### 安装指南

```bash
# 1. 安装 Python 依赖
pip install -e .

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填入 OPENROUTER_API_KEY

# 3. 设置数据库
createdb life_patterns
psql life_patterns -c "CREATE EXTENSION IF NOT EXISTS vector;"

# 4. 运行服务
uvicorn src.main:app --reload --port 8000
```

### 工作流程

```
用户输入 → 创建记录 → 异步分析 → 模式检测 → 洞察生成
```

### API 使用

```bash
# 创建记录
curl -X POST http://localhost:8000/api/v1/records \
  -H "Content-Type: application/json" \
  -d '{"content": "今天和领导沟通很紧张，又开始怀疑自己能力不行"}'

# 获取洞察
curl http://localhost:8000/api/v1/insights
```

## fabe-skill

**FABE 销售话术生成工具 - 将产品技术语言转换为用户语言**

### 触发方式

```
/fabe [产品技术信息]
/fabe [产品技术信息] [场景描述]
```

### 工作流程

```
步骤 1：输入解析 → 识别产品类别、提取技术特性
步骤 2：FABE 分析 → F/A/B/E 逐项分析
步骤 3：场景适配 → 按指定场景或推荐场景输出
```

### 输出格式

```
## 📊 FABE 分析表
| 技术语言 (F/A) | 用户语言 (B) | 证据 (E) |
|--------------|------------|---------|
| [技术参数] | [用户场景 + 价值] | [如有证据] |

## 📝 [场景名称] 文案
[根据场景动态生成的内容]
```

### 受众权重

| 受众 | B·利益 | F·特性 | A·优势 | E·证据 |
|------|--------|--------|--------|--------|
| 普通消费者 | 🔴 核心 | 点到为止 | 日常比较 | 生活故事 |
| 媒体编辑 | 故事性 | 足够深度 | 🔴 核心 | 可验证 |
| 技术发烧友 | 圈层认同 | 🔴 核心 | 真实对比 | 🔴 可自验证 |

## Deeper-analysis

**元认知提问工具 - 用第一性原理角度引导用户深入思考**

### 触发方式

```
帮我分析问题
怎么想清楚这个问题
如何思考
分析一下这个问题
```

### 工作流程

```
步骤 1：元认知校准 → 我的问题确实是问题吗？
步骤 2：视角切换   → 我是不是被自己的视角限制了？
步骤 3：连续追问   → 我看到的只是表面吗？
步骤 4：问题重构   → 这个问题本身对吗？
步骤 5：反事实思维 → 我是不是默认了错误的现实？
步骤 6：系统思维   → 我是不是只看了一点，没看整体？
步骤 7：假设驱动   → 我怎么知道我想的是对的？
```

### 引导程度选择

| 等级 | 说明 |
|------|------|
| 1 级 | 最少引导：只问核心问题 |
| 2 级 | 轻度引导：问问题，偶尔给方向 |
| 3 级 | 均衡引导：问问题 + 提供选项（推荐） |
| 4 级 | 深度引导：主动推荐，你只需选择 |
| 5 级 | 完全引导：带着你走完每一步 |

# 视角切换 - 详细指南

## 核心能力

从"默认视角"跳到"新的观察坐标"。创新往往不是答案不同，而是"观察位置"不同。

## 常用视角坐标

### 用户视角
把自己换成真实用户，尤其是：
- 孩子/老人/新手
- 极端用户（过度使用/几乎不用）
- 不同文化背景的用户

**示例：**
- 默认："如何让 App 功能更强大？"
- 孩子视角："这个 App 哪里让我觉得笨？"

### 第一性原理视角
剥离所有类比和假设，回到最基本的事实：
- 人为什么需要移动？→ 汽车革命
- 人为什么需要住宿？→ Airbnb
- 人为什么需要拥有？→ 共享经济

**示例：**
- 默认："如何做更快的马车？"
- 第一性原理："人为什么一定要用马车移动？"

### Outsider 视角
假设你是完全的外行人：
- 这个行业有哪些"理所当然"？
- 哪些规则其实没人规定？
- 如果从零开始会怎么做？

### 长期视角
把时间轴拉长：
- 5 年后这个问题还重要吗？
- 10 年后的用户会怎么想？
- 现在的"创新"会是未来的"落后"吗？

### 系统视角
从单点跳到整体：
- 这个行为在什么系统中发生？
- 系统结构如何塑造了这个行为？
- 改变哪个杠杆点最有效？

### 极端用户视角
从极端用户角度看：
- 完全不懂技术的人会用吗？
- 时间非常紧张的人会用吗？
- 预算非常有限的人会买单吗？

## 使用模板

```markdown
## 视角切换工作表

**当前问题**：[你的问题]

**默认视角**：[你现在的观察位置]

**尝试视角**：[选择一个新视角]

**新观察**：
- 看到了什么之前没看到的？
- 哪些假设被挑战了？

**新问题**：[从这个视角看，问题变成了什么？]

**关键洞察**：[用一句话总结]
```

## 经典示例

### 示例 1：产品创新
```
原问题："如何做更快的马车？"
视角切换：第一性原理视角
新问题："人为什么一定要用马车移动？"
洞察：移动的本质是位移，不是马车 → 汽车革命
```

### 示例 2：用户体验
```
原问题："如何让 App 功能更强大？"
视角切换：孩子视角
新问题："这个 App 哪里让我觉得笨？"
洞察：功能越多越复杂，孩子需要的是简单直接
```

### 示例 3：商业模式
```
原问题："如何开更多酒店？"
视角切换：系统视角
新问题："住宿需求如何被满足？"
洞察：大量闲置房源 → Airbnb 模式
```

## 常见陷阱

- ❌ 只换词汇不换视角（伪切换）
- ❌ 选择自己熟悉的"新视角"
- ❌ 切换后没有深入挖掘
- ❌ 一次切换太多视角
